# SPL - "System Programming Labs"

Explore System Programming Labs (SPL) focused on low-level programming with C and assembly. This repository includes hands-on projects that provide practical experience in system programming concepts. Topics and projects covered include:

- **Pointers and Memory Management:** Understand pointer manipulation, dynamic memory allocation, and memory layout.
- **Binary File Handling:** Work with binary file I/O and understand their structure.
- **System Calls:** Learn to use system-level APIs for file operations, process control, and inter-process communication.
- **Debugging Techniques:** Use debugging tools like GDB to troubleshoot and analyze low-level programs.
- **Command Interpreters:** Develop simple shell programs and command interpreters in C.
- **Assembly Language Programming:** Perform tasks using assembly language, focusing on low-level operations and optimization.
- **ELF File Handling:** Analyze and manipulate Executable and Linkable Format (ELF) files for deeper system insights.

## Repository Highlights

- **Detailed Projects:** Each topic includes complete implementations and exercises for deeper understanding.
- **Comprehensive Documentation:** Inline comments and separate documentation files for clear explanations.
- **Test Cases:** Ensure correctness of implementations with provided test cases and scenarios.

## Prerequisites

- Basic knowledge of C programming.
- Familiarity with assembly language concepts is helpful.
- Access to a Linux system for running and testing projects.

## How to Use This Repository

1. Clone the repository: `git clone https://github.com/username/SPL-System-Programming-Labs.git`
2. Navigate to the desired project: `cd SPL-System-Programming-Labs/<project>`
3. Follow the README in each project folder for specific setup and usage instructions.

## Tools and Dependencies

- A C compiler like GCC.
- An assembler such as NASM for assembly tasks.
- GDB or another debugging tool for troubleshooting.
